# Abroc Cafe & Kitchen ☕✨

> Artisanal Food & Specialty Coffee | Sirhind, Punjab

Welcome to the official web repository for **Abroc Cafe & Kitchen**.

## 🌐 Live Website
The website is published on GitHub Pages:
**[https://preeti-kaur245.github.io/abroc-cafe-and-kitchen-/](https://preeti-kaur245.github.io/abroc-cafe-and-kitchen-/)**

## 🍽️ Features
- **Cinematic Visual Experience**: Interactive 3D coffee visualizer, ambient lighting effects, and custom cursor animations.
- **Dynamic Artisanal Menu**: Filterable menu with dish categories, dietary tags, spice levels, and customer ratings.
- **Interactive Table Reservation**: Real-time table booking modal with instant confirmation.
- **Instant WhatsApp Order**: Direct order integration via WhatsApp.
- **Customer Reviews & Community**: Real customer reviews and Instagram visual gallery.
- **Fully Responsive & Accessible**: Optimized for mobile, tablet, and desktop screens.

## 🚀 Tech Stack
- HTML5 / CSS3 (Custom Design Tokens & Responsive Layouts)
- Vanilla JavaScript (Dynamic UI, Category Filtering, Cart & Modals)
- Three.js (Interactive 3D Atmosphere)
- GitHub Pages (Deployment)
